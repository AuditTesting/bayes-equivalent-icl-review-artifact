Each JSON describes a separate frozen study. Populations, resampling units, strata and percentile conventions are not interchangeable.

- Figure 2: original depth/longitudinal saved seed statistics and bootstrap statistics.
- Figure 3: relevance-controlled extended-training trajectory bootstrap.
- Figure 4: S22 common-four-cell A/C/D/E bootstrap, including D-A and E-C. Historical S21 intervals are not substituted.

No reconstruction script draws random numbers. Saved per-draw statistics support interval reconstruction where original index arrays are not included. This reconstructs those stored uncertainty calculations, not the whole upstream resampling pipeline from raw training data.
